# Agency guide

Demo: `amira@demo.workspring.test` owns the synthetic agency "Spring Build Collective"; `youssef@demo.workspring.test` is a member.

- **Create**: Workspace → *Agency* → name + description (freelancer capability and a verified email required; one owned agency per account).
- **Public page**: tick *Show a public agency page* → `/agencies/<slug>` lists the team with links to published profiles.
- **Invite**: enter the freelancer's WorkSpring email and a role. The form never reveals whether an email has an account. Invitations expire after 14 days and can be revoked.
- **Roles**: owner (everything, incl. changing roles), admin (invite, remove members, edit profile), member (view team). Ownership transfer is not supported in this build.
- **Remove / leave**: soft removal; the member's own account, contracts, earnings and history are untouched and access ends immediately. The owner can't be removed.
- **Boundaries**: agency roles never grant access to a member's messages, contracts, earnings or credentials. Agency-level contracts (hiring the agency as a whole) are **not offered** yet; clients hire members individually.
